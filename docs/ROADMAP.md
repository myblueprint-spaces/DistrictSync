# Roadmap

The backlog no longer lives in this repo. Work is tracked on the Jira DSYNC board:
<https://myblueprint.atlassian.net/jira/software/projects/DSYNC/boards/238>. Features, bugs, process and doc changes, and releases are tickets there; see [Release process](developer/release.md) for the conventions. Do not recreate a task list in this file.

## What stays in the repo

- [`DECISIONS.md`](DECISIONS.md): dated decisions and their reasons.
- [`INVARIANTS.md`](INVARIANTS.md): rules that must not be inverted.
- [`CHARTER.md`](CHARTER.md): what the product is for.
- [`../CHANGELOG.md`](../CHANGELOG.md): what shipped, per release.
- Product docs (`PRODUCT.md`, `PRODUCT_SPEC.md`), developer docs (`docs/developer/`) and partner docs (`docs/partner/`).

## The 2026-09-03 audit snapshot is retired

This file used to hold a prioritized backlog from the 2026-09-03 audit, plus older housekeeping and plan notes. That snapshot has been retired rather than migrated: it was a point-in-time list, much of it already resolved, and the board is now the single place a task is tracked. The old text is not lost. It remains in git history (view an earlier revision of this file); open items worth keeping are raised as DSYNC tickets when they are picked up.
