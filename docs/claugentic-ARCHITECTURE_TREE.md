## src/etl/  (ETL pipeline)

- `src/etl/extractor.py` — `DataExtractor`: ONE public entrypoint, `load_data`, over a bytes-based core — multi-encoding fallback (UTF-8 → Latin1 → CP1252), auto-delimiter detection, unquoted-`Section` row repair; resolves each configured filename exactly then case-insensitively (a COLLISION raises); `load_from_bytes` retired by plan 0051; normalises column names; `ExtractionError` (an `EtlError`: `input_unreadable`) on unparse-able content.
- `src/etl/transformer.py` — `DataTransformer` facade: delegates to entity transformers via `TransformContext`; read-only school-year/homeroom/blended properties (views over the Classes-published `ClassArtifacts`) for test access; `data_errors_mark`/`rollback_data_errors` (0053 S2; used by the S4 bulkhead to drop an isolated entity's entries); full facade retirement remains a ROADMAP item.
- `src/etl/pipeline.py` — ETL orchestration: `run_pipeline` = Extract → `observe_source_columns` (0053 S6, advisory, shared with Convert) → `run_transform(*, ledger)` (one outcome per entity; the ONE entity bulkhead, S4) → integrity gate → Loader + anomaly/quality → `PipelineResult` (exit 1/3). ONE `build_run_record` → log line + non-fatal store (none on `dry_run`). Output pre-flight (0050); `dry_run_entity_lines`.
- `src/etl/loader.py` — `DataLoader` writes field-ordered CSVs (`utf-8-sig` BOM; plain UTF-8 for `_NO_BOM_ENTITIES`=`StudentAttendance`); `csv_encoding()`/`select_ordered()` single-source the BOM + column rules; `save_all()` stages to `.tmp_<ts>/` then `_commit_staged` commits atomically (`.bak_<ts>/`+`os.replace`; rollback is per-file BEST-EFFORT); + `archive_stale_outputs()`. `output_target_problem()` = the 0050 output-folder pre-flight.
- `src/etl/preflight.py` — Pure pre-flight column derivation (no pandas/pathlib/flet): `expected_columns` (every field-map variant, tagged `ExpectationOrigin`, ACTIVE entities); `preflight_report` = the creator's in-no-file claim; `missing_columns_by_entity` (0053 S6) = the run's OWN-file claim (`OBSERVATION_SCOPE`); `label_vocabulary_by_entity` (S7) = each entity's config-declared labels. - `src/etl/outcomes.py` — Stdlib-only per-entity outcomes (0053 S2): `ENTITY_CRITICALITY` (D1; unlisted ⇒ CRITICAL) + `DEPENDS_ON`; S8 `MAY_BE_EMPTY` (D5); closed kinds/reasons; frozen `EntityOutcome` (S6 `missing_mapped`, S7 `labels`/`file_label`); `OutcomeLedger` (+`record_failure`); `apply_observation`; S7 `safe_label` (the ONE label check) + `apply_labels` (the ONE producer); record pair + TOTAL reader; `failed_entities`.

- `src/etl/sync_window.py` — Pure seasonal sync-window predicate (`today`-injected, no `date.today()` inside): `in_sync_window(today, start_md, end_md)` (wrap-around / non-wrapping / one-day, boundary-inclusive, leap-day clamp via `(month, day)`-tuple compare) + `next_resume_date`; boundaries validated via `validators.validate_month_day`.
